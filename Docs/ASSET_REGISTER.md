# Asset register

Packs in use are listed below (CC0 unless noted); everything else is generated geometry or project-made textures (Prototype/ThirdParty/GeneratedTextures, from Tools/make_textures.py). Pack folders each carry a LICENSE.txt; Unity creates the .meta files on import.

## Candidate categories

Store furniture, jewelry props, architectural materials, torch props and pavement details. Use primitive geometry for the initial layout. Cones, markers, tape and static glass can be made specifically for the project.
