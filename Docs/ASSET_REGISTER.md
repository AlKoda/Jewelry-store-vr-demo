# Asset register

Packs in use are listed below (CC0 unless noted); everything else is generated geometry or project-made textures (Prototype/ThirdParty/GeneratedTextures, from Tools/make_textures.py). Pack folders each carry a LICENSE.txt; Unity creates the .meta files on import.

## Candidate categories

Store furniture, jewelry props, architectural materials, torch props and pavement details. Use primitive geometry for the initial layout. Cones, markers, tape and static glass can be made specifically for the project.

## Realism packs (October 14–15)

Twelve packs fetched and converted by Claude's asset-sourcing workflow, each checked by an independent license and file review and then repaired: PBRInterior, PBRExterior, NightSky, JewelryModels, ForensicModels, StreetModels, InteriorModels, WallGraphics, SurfaceDecals, NightSoundscape, Music, PeopleModels (Prototype/ThirdParty/<pack>/, each with LICENSE.txt, README.md and a per-file sources.json; build scripts in Source~, which Unity ignores). About 262 MB in total, so they are not in the Downloads ZIP: Start-Demo.cmd mirrors Prototype/ThirdParty into UnityProject_Demo, and since October 15 Open-Unity-Glass.cmd mirrors it into UnityProject_Glass (both through Tools/sync-project.cmd). The October 15 wiring batch places the rows marked **Wired** in the night store, each with a primitive or procedural fallback when the file is missing. None has been imported in Unity yet (unverified, never compiled); see the top entry of HANDOFF.md. LOD1/LOD2 variants and atlas pages made for the wiring are listed in each pack's README, sources.json and LICENSE.txt.
