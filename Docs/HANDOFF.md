## What the project is

An instructor-led VR crime-scene demo: a jewellery store at night after a break-in, with the police just arrived. The trainee walks the scene, places cones, markers, tape, scales and lamps, photographs evidence and uses white and UV torches. A presenter drives it from the PC. There are no scores, timers or forced sequence. It runs on a Windows PC with keyboard and mouse, or with a Meta Quest 3 over Quest Link or Air Link.

Unity 6000.6.2f1, Built-in render pipeline, no packages (Package Manager is broken on the PC; every launcher uses `-noUpm`).

## One project, edited in place

There is **one** project. The scene in use is the **night store** (`JewelryStoreNight`, generated by `NightStoreBuilder`).
- All source is in `Prototype/`. The Unity project folders on the PC (`UnityProject`, `UnityProject_Demo`) are copies that `Tools/sync-project.cmd` refreshes, and edits made inside their Scripts/Editor/Shaders/ThirdParty folders are overwritten.
- `Downloads/JewelryStore_Unity6000.6.2f1.zip` is the one project snapshot, refreshed with `python3 -I Tools/zip_snapshot.py` after every batch. Never add a second zip, scene or project for a new batch.

## How to run it (Windows PC)

| Double-click | What it does |
|---|---|
| `Play-Keyboard.cmd` | Pulls, builds `Builds\Windows\JewelryStoreDemo.exe` if the source changed, starts it in keyboard/mouse mode. Add `bake` for baked lighting (final look), `rebuild` to force a preview rebuild, `run` to skip the build. |
| `Play-VR.cmd` | The same build, started with `-demo-mode vr`. Quest Link or Air Link must be running; without a headset the demo stays on the desktop and says so after 8 s. |
| `Open-In-Unity.cmd` | Unpacks the snapshot into `UnityProject` (or reuses an existing `UnityProject_Glass`), syncs Prototype into it and opens the Unity editor. |

**Known gap:** the build has no XR loader yet (no OpenXR package, because of the broken Package Manager). Until OpenXR is installed on the PC, `Play-VR.cmd` cannot drive the headset. See [DELIVERY_PLAN.md](DELIVERY_PLAN.md).
