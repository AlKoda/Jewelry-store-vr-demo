# Demonstration run sheet

For the October 27, 2026 opening day. Roughly eight minutes per visitor group. The instructor narrates; the software judges nothing.

## Before the doors open

1. Charge the headset and both controllers; test the Quest connection (or, for the desktop fallback, the mouse and keyboard).
2. Start the demo from Run-Demo.cmd (standalone build) or, as a fallback, from the Editor with the Expanded scene and Play.
3. Confirm the monitor shows the headset view and the presenter panel (Tab toggles the panel on the desktop view).
4. Open the photo folder once (panel button) so it is already indexed and the path is known.
5. Reset the scene (two clicks on the reset button) so the first group starts from the untouched state.
6. Keep the backup build copied to a second drive or USB stick.

## Run sheet

| Minute | Instructor | Visitor |
|---|---|---|
| 0 | Explain the scenario: a jewelry store robbed overnight; the officer's first job is to secure and document, not to solve. | Puts the headset on at the start position inside the entrance. |
| 1 | Point out the broken window, the empty displays and the shoe print. Say the street outside is not part of the scene. | Looks around; walks or teleports to the display islands. |
| 2 | Ask what should be protected first. Suggest cones around the shoe print and the glass. | Spawns cones (1 / rack / tool menu), places them. |
| 3 | Introduce numbered markers: one per item of evidence, in the order found. | Places markers 1–3 at the print, the display damage and the safe room door. |
| 4 | Scene tape between two posts closes off the safe room. | Spawns two tape posts, places them, connects them (T on each post / trigger). |
| 5 | Photograph each marked item with the camera. Mention that the photos are saved on the PC for review. | Picks up the camera (F / grip), photographs (P / trigger). |
| 6 | Walk into the safe room: open safe, discarded torch. One more marker and photo. | Places marker 4, photographs. |
| 7 | Open the photo folder on the monitor and review the images with the group. | Removes the headset. |
| 8 | Reset the scene for the next group. Photos remain in the folder. | — |

## If something goes wrong

- Tool out of reach or through a wall: Delete (or the remove action) on it, spawn another.
- Player stuck or outside: Home returns to the start position.
- Headset drops out: continue on the desktop view with mouse and keyboard; the same panel and keys work.
- No photo saved: the status board and panel show the capture error; the folder button still opens the folder.
- Demo crashes: restart from Run-Demo.cmd; nothing needs to be re-placed, the scene starts clean.

## After each group

Reset (two clicks). Glance at the status board: "0 deployed, next marker 1".
